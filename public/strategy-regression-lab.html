官方來源的排名資料不使用 FinMind；選 FinMind 來源則行情也會使用 API 配額，且需要 backer／sponsor 全市場權限。補齊個股籌碼沿用 r18 研究快取，可能使用 FinMind API 配額；重新搜尋只讀本機資料，不呼叫上游。快取保存在這個瀏覽器，可匯出備份。請先在原掃描器設定 FinMind Token。

固定池不抓每日全市場排名，依「固定池行情來源」下載。純價量模式不抓籌碼；固定池另選 FinMind 時行情會使用配額。股票期貨按鈕填入目前名單（沿用舊版官方頁面解析，請核對名單），凍結後不自動刷新；這是標的股票現貨回測，不是期貨合約回測。今日成分回測歷史存在存活者與選樣偏差，只作探索。免費來源仍可能拒絕存取，失敗會保留已完成快取並停止。0050 歷史交易日作日曆代理，不是官方完整日曆。

價量分數不是原版 V4.4：Setup＝MA20／MA60 趨勢；Opportunity＝5日動能＋量比；Entry＝前20日高點突破＋動能＋量比；Hold＝收盤／MA20。分數及日變化的權重在訓練／驗證期選擇。原版仍要求完整籌碼，缺值不補零。未處理股息與除權息，結果為初步價格報酬研究。

按訊號日分別算截面 Spearman IC，再取日期平均；Q5−Q1 為高低分組平均淨報酬差（百分點）。h 代表 T+1 開盤買進、T+h+1 開盤賣出。每組至少 20 檔；分組邊界同分不計價差。測試統計僅作診斷，不用來選參數。

成交與限制
期間按日期切成 55% 訓練、20% 驗證、25% 最終測試。每段最後 26 個交易日不開新倉，供最長 20 日持有及退出緩衝；跨界未平倉明確計數，參數不得入選。預測標籤在各段結束以前完整實現。
進出場均由收盤訊號觸發，最早次一交易所交易日開盤成交。買單當日不能成交即取消；賣單不能成交則延後。零成交、缺價或一價鎖住的日 K 不假設可成交；持倉退出不受前百名限制。
有未平倉時整段平均淨報酬不顯示，其餘統計僅供診斷。績效為每筆等名目本金交易的淨報酬，個股持倉不重疊，但多股可重疊；沒有資金／部位上限，因此不是可直接實現的投資組合報酬、年化或 Sharpe。費率為可調研究假設，未計最低手續費、整張限制、股息、除權調整或市場衝擊。
歷史官方名單避免以今日名單選股，但分數暖機、歷史籌碼缺漏與下市後退出仍可能造成偏差；完整度另列。行情或日期無法驗證會停止，不以最新行情代替。重複看測試結果後改設定仍會污染樣本外，應再保留新的未看過期間。
