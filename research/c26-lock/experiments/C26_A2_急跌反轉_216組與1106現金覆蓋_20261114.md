# C26 急跌反轉 A2｜創意 2026/11/06 與完整歷史跨參數檢核

**研究日期 2026/11/14，僅供研究，不是正式 C26 進出場策略，也不代表券商成交。**

## 研究結果摘要
原始 C26 **仍是** +1,720.50%／MDD −17.99%（2021/01/06–2026/10/27、往返0.5855%）。
原版 C26 不會在 2026/11/06 買入創意。任何反轉旁路需要**另外允許冷盤時開新倉**，不應悄悄關閉既有防守條件。

### 1. 五年 216 組壓力測試（獨立帳本）
- 原始資料：私有 FinMind 70 個月份、233 檔股票，2021/01/06～2026/10/27。
- 候選在前一交易日收盤已知：跌幅≥8%／9.5%，收在當日最低附近，低於20日EMA≥4%，量比≥0.8／1.2；一律按事前量比排序，不對創意等股票設白名單。
- 下個開盤日跳空跌 3%／5%／7% 且開盤價低於預設觸發價後，盤中往上碰到「前收 × 98%／96%／94%」才假設觸發；最多前1／3／8檔。隔日開盤出場，往返0.5855%，另測買賣各0或0.5%額外滑價。
- 共216組；52組具20筆以上模擬成交；其中15組設定在**兩種滑價**下、2021～24與2025～26兩區間皆正報酬、且≥20筆成交。
- 資料仍有股期名單存活偏差、減資除權息、OHLC觸價非逐筆確定成交，且整套研究是因為已知2026/11/06事件而發想，**兩段績效不能當作乾淨的樣本外驗證**。

### 2. 研究候選「A2」
| 參數 | 設定 |
|---|---|
| 前一日跌幅 | ≥8% |
| 收盤相對日低點 | ≤+0.5% |
| 20日EMA | 收盤低於EMA至少4% |
| 成交量 | 相對20日均量≥1.2 |
| 排名 | 全部233檔量比最高前3 |
| 隔日開盤 | 跳空跌≥3%，且須低於預設突破觸發價 |
| 突破買進 | 事前固定「訊號收盤 ×96%」依台股tick向上取價 |
| 賣出 | 隔一個交易日開盤 |
| 買賣成本 | 合計0.5855%，另保守加入兩端各0.5%滑價 |

- 2021–2026/10：**27筆模擬交易**，勝率62.96%，獨立條件帳本+12.6918%，已平倉帳本最大回撤−2.864%（**不是**完整持倉最大回撤、更**不是**C26 MDD）。
- 2021–2024獨立帳本+7.363%，2025–2026/10 +4.964%；各年度的已平倉帳本皆略為正報酬。
- 27筆62.96%勝率的 Clopper-Pearson 95% 區間約42.4%～80.6%，**樣本非常有限**。
- 27筆「滑價後買價高於當日最高價」=0，但未核對每一筆逐筆觸價、排隊或真實委託回報。
- 因為從216組中挑出，不能將最佳結果稱為無過擬合。

### 4. 同一份 C26 前向原帳本的現金覆蓋壓測
- 11/05 原C26 NAV=17.03507005，以初始3百萬元換算為5,110.52萬；持股2801／3374，約97.91%現金；11/06原C26目標曝險僅**0.10419%**。
- 在原策略**不變**的情況下，假設臨時用5%總預算均分給事前排名前3股，只有3443日K可能觸價，實際投入約1.667% C26資產，11/09獲利對原本C26 NAV增加約 **+0.0630%**；再加每側0.5%滑價約 **+0.0458%**。
- 若把5%總預算均分前8股，當天3443及3037可能觸價，獲利約 **−0.0067%**；再加每側0.5%滑價約 **−0.0191%**。
- 以上是**增量現金覆蓋估算**，只重估這兩天股票及現金，不是將新增股票真正送入C26凍結Python引擎五年重跑；**不可以**把這個結果加到C26 +1720%當成正式績效。

## 驗收與不升級條件
- 為所有 27 筆進場至少抽樣逐筆核對買停損觸價、委託成交限制與隔夜跳空；需要歷史股期名單、減資除權息資料，防止創意單一事件過擬合。
- 必須在原 C26 的**同一現金帳本**加入新進場：最多8股、單檔≤30%、持股與現金負債及現有買賣衝突均正確；盤前可掛單、不使用當日最高價決定委託價、模擬開盤跳空、成本0.5855%。
- 需要具體允許多少資金突破原「MARKET_COLD／DD_Gate」的策略變更；不可偷改閘門。
- 驗證 2021～2026 各年、±1日訊號延遲、滑價±0.5%、參數相鄰連續性、最大日內風險與正式C26 MDD。**未經此驗證，不修改正式 C26／FC23／R1494-A。**

## 5. 80組觸發價鄰域與實際 Tick 延遲再驗證（追加研究）
4% 折價不是已證明的穩健最佳點。先看到216組結果後，才追加80組鄰近參數；**這仍是樣本內選取，不能宣稱獨立測試通過**。

無論 216／80 組，均未真正把新交易注入 C26 Python 原始現金/持倉引擎。
4%附近3.5%與4.5%雖兩段仍為正，但交易筆數、收益與可成交假設波動很大，**仍有觸發價甜蜜點風險**。

11/06 3443 真實歷史 Tick 對新6,150元觸發價：
- 09:53:10.567123 第一筆正好6,150元；同價出現45筆成交，成交路徑比6,025元更有證據。
- 若因條件單觸發/處理延遲10秒，10秒後第一筆觀測價格6,170元，含原成本至11/09首筆6,420元淨利+3.44%；延遲30秒觀測6,215元則淨利+2.69%。這些只是**指定延遲下的第一個觀測印價，不是可保證的券商成交價**，且延遲不代表可以事後挑有利價。
- 注意買停損市價單不保證限價成交，尤其急跌急彈；停損限價單則可能完全不成交。券商實際是否支援此功能需確認。

## 目前研究決策
**暫不升級正式 C26**。保留 A2 作研究候選：一旦原 C26 在冷盤下特別開倉，必須在原帳戶逐日重算 DD／現金／≤8檔／≤30%單檔／0.5855%成本，並把多日無法賣出的跌停事件及交易延遲纳入壓測。模型研究中的6年微小正報酬不等於足以證明穩定收益。
