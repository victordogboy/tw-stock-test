# C26-A24｜歷史消息初步資料集驗證（研究用，不得交易）

## 執行狀態（已實際執行）

- 資料源：FinMind `TaiwanStockNews`，使用 GitHub Actions Secrets 中既有的 `FINMIND_TOKEN`；沒有洩漏憑證或原始授權新聞標題
- 样本母體：先前 A20 已固定之 **26 次崩跌訊號**，每次在訊號收盤時以 `0.5×precrash_rs20_pct +0.5×signal_day_return_pct` 選價量前五，另從其餘股票用預先固定 SHA256 種子選五檔對照，合計 **260 股票／事件觀察**
- 研究期間：2021-05-07～2026-09-16，共26個事件；未對後續報酬挑新聞樣本
- 新聞時間：僅使用**訊號日之前一個日曆日**的新聞，來源 `date` 具有時分秒但時區與「最初發布」沒有第三方核對；拒絕使用訊號當日或更晚的文章
- 先前API帶 `end_date` 之260筆查詢全面HTTP400，**沒有列入**任何結果；改用本帳戶已核實的單日 `start_date` 查詢，並檢查回傳日期後，成功260/260，無請求失敗

API返回1,338筆消息（含重複標題）；去重後保留1,131筆。

26次崩跌事件裡有**22次**價量前五的新聞筆數多於同事件固定隨機對照；但只比較「非股價報導、包含財務、業務、公告等關鍵字」的筆數時，僅**15次**較多。

**解讀：價量強勢股較受媒體關注，尤其股價反應性新聞很多；這是當下市場注意力的關聯，並未證明新聞可預測下一段漲幅，也沒有驗證新聞是股價因果原因。**

## 成交與因果安全

- 僅分析新聞報導時間**早於訊號日**的資訊，並將來源時區、真正首次發布時間列為**未核實**；不能因此宣稱所有訊號已具備 Point-in-Time 的可交易證明
- `factual_preprice_count` 僅指標題符合業務／財務／公告字詞且未符合價格反應字詞，**不等於消息確認為真，也不等於利多**
- 目前尚未把260組新聞因子與對應 **A20 逐股五日模型淨報酬標籤**完整合併，也未做純新聞／價量／融合三模型跨年度驗證；**不存在經稽核的A24預測勝率、超額報酬或C26同帳本提升**
- MOPS官方重大訊息尚未取得整套2021～2026歷史公告；證交所公開每日快照不能替代歷史公告庫
- 原版C26**完全不修改**；新增的新聞研究程式不會產生券商委託

## 後續驗收而非參數最佳化

1. 用同一 A20 股票－事件鍵 `signal_date + code` 對齊五日淨報酬與成交可行性，缺值及漲停不可成交不得自動剔除
2. 以2021～2024資料擬合價格基準＋新聞關鍵字及去價股價報導特徵，2025～2026驗證，並以事件bootstrap比較增益區間
3. 分別加入MOPS歷史正式發言時間，確認發布時間可靠；再對比未來 1／3／5 日表現
4. 只有跨事件、跨年度、成交成本0.5855%、不靠單次行情仍增加C26同帳本報酬且回撤≤20%，才考慮正式策略
